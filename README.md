# Happy Birthday, Mero Budii 😭💋

A private birthday universe made by Ayush for Mansun.

## Setup
```bash
bun install      # or npm install
bun run dev      # http://localhost:8080
bun run build    # production build
bun run test     # password tests
```

## Personalize
- Text: `src/lib/content.ts`
- Photos & music: see `ASSETS_README.md`

## Deploy
Easiest: click **Publish** in Lovable. Otherwise run `bun run build` and deploy the output to a host that supports TanStack Start (e.g. Cloudflare Workers).

Note: the password is checked in the browser — fine for a sweet surprise, not real security.
